# AI Coding Assistant (Phidata)

This project is a simple AI agent built using the **phidata** framework.
The agent acts as a coding assistant that can answer programming questions, explain code, and suggest improvements.

##  Features

* Answer coding-related questions
* Explain code in a simple way
* Suggest improvements and fixes

##  Installation

1. Clone the repository:

```
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

2. Install dependencies:

```
pip install -r requirements.txt
```

##  Usage

Run the application:

```
python app.py
```

Then type your question in the terminal.

Type `exit` to quit.

##  Requirements

* Python 3.10+
* phidata

##  Notes

* This project uses a local or API-based language model depending on configuration.
* Make sure your environment is properly set up before running.
